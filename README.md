# Trabalho 2ª Etapa - Inteligência Artificial

## Sistema Especialista Inteligente para Mapeamento, Compatibilidade e Trilha de Carreira em TI

Projeto prático desenvolvido para a disciplina de Inteligência Artificial.

Para instruções completas sobre o sistema especialista, arquitetura, base de conhecimento e execução, acesse o diretório [`sistema_carreiras/`](./sistema_carreiras/).

## Estrutura do Projeto

- [`sistema_carreiras/`](./sistema_carreiras/): Código-fonte e artefatos do sistema.
  - `regras_carreiras.json`: Base de conhecimento declarativa.
  - `motor.py`: Motor de inferência e cálculo de pontuação ponderada.
  - `roadmap.py`: Gerador de roadmaps e trilhas de aprendizado.
  - `app.py`: Interface interativa em Streamlit (Wizard).
  - `tests/`: Testes automatizados e casos de borda.
  - `requirements.txt`: Dependências do projeto.
  - `README.md`: Documentação detalhada da aplicação.
